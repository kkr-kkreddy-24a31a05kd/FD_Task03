# FD_Task03

The **Weather App** is a simple and responsive web application built using **React.js** that allows users to search for any city and view its current weather conditions in real time. The application integrates with a weather API such as **OpenWeather API** to fetch live weather data and display important details including **temperature, weather condition, humidity, wind speed, and location information**.

The user-friendly interface features a clean search bar where users can enter a city name and instantly receive updated weather information. React state management is used to handle user input, API responses, loading states, and error handling, ensuring a smooth and interactive user experience.

### Key Features

* Search weather by city name
* Real-time weather data using OpenWeather API
* Display temperature, weather condition, humidity, and wind speed
* Responsive and modern user interface
* Error handling for invalid city names
* Dynamic updates without page refresh
* Loading indicator while fetching data



### Learning Outcomes

Through this project, developers gain hands-on experience with:

* Integrating third-party APIs in React applications
* Managing component state using React Hooks
* Handling asynchronous data fetching
* Working with user input and forms
* Displaying dynamic data in a responsive UI
* Implementing error handling and loading states

This project is ideal for beginners looking to strengthen their React fundamentals while building a practical application that demonstrates real-world API integration and dynamic user interfaces.
